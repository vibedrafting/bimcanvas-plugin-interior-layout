# 卫生间策略

适用：tags 含 `shower`/`toilet`/`washing` 的空间。

## 这类空间怎么想

卫生间是**模板匹配型空间**：测量空间 → 选布局模式 → 参数化定位洁具。你是工程师——精度优先、自由度极低。

和客厅、卧室相反，卫生间**收敛到单一最优解，不发散多方案**。洁具是定尺功能件、空间小、约束硬，最优布局近乎唯一；硬凑第二个方案，只能靠违反规则（换一面更差的墙、破坏开阔侧动线）来制造"差异"——那不是多样化，是次优。**先把这一个最优解做对、做透。**

## 怎么排：四个思考支点

每条带 why，遇到规则没覆盖的边界，从原理自己推。

**① 台盆墙长优先 —— 决定墙面归属**

台盆是卫生间里唯一"功能价值随墙长持续增长"的洁具：墙越长 → 台面越大 → 双盆 / 落物 / 镜柜延展。马桶（定尺 400）、淋浴房（≤1200 即饱和）、浴缸（~1700）都早早饱和，给再长的墙也用不上。

所以：**把最长、连续、不被门洞打断的那面墙留给台盆**，其余定尺洁具占剩下的墙、或共用一面墙上下叠放。

台盆沿墙的一端**贴死相邻墙角**、不留窄缝（哪一端随模式：一字 / 半卫贴入口侧墙角，矩形 / 钻石 / L型贴所在墙的连续端角）。`【自查·坐标】台盆至少一端贴相邻墙角 gap=0；出现 1–600mm 非通道窄缝 = 不过。` 贴角是正确定位、非"入口局促"——入口缓冲靠对侧通道，不靠把台盆推离墙角；识图报"入口 / 台盆局促"时回核本锚、不据此移台盆。

> 推论：门把空间分两侧，门那侧的墙被门洞切断、本就不连续 → 放可分段的马桶 / 淋浴；对侧完整长墙 → 留给台盆。

**② 入口 → 深处：台盆 → 马桶 → 淋浴**

洗漱在入口（高频、进出即用），如厕居中，湿区进最深。why：干湿分离、水汽不外溢、淋浴隐私最高。

马桶**中心线对齐"可用如厕段"中心**（= 台盆远端边沿 ↔ 屏 / 湿区边沿），不从台盆边缘顺势贴拼——马桶不是台盆的附属件。`【自查·坐标】坐便器中心线 == 可用如厕段中心（偏差≤50mm）。`

**③ 建筑预留的凸凹，是给你分隔湿区用的锚点**

建筑在前、方案在后。户型里的管井 / 结构垛不是麻烦，是**预留给方案期布置淋浴屏、界定湿区的天然界线**。一字屏顺着凸凹下沿落位，把凸凹**吞进湿区**，干区那面长墙就恢复平直连续——正好喂给支点 ① 的台盆。

**④ 避窗规则取反**

与其他房间相反：**淋浴可临窗**（采光通风好）；**马桶避免正对窗**（隐私）；花洒装湿区内的**实墙**、不装窗墙（走管需实墙支撑）。

## 选哪个模式（决策树，命中即停）

模式名 = 淋浴形态。按顺序判断：

1. 无淋浴需求（tags 无 `shower`）→ **半卫**
2. 短边 ≤ 1800mm（窄长，对侧塞不下洁具）→ **一字淋浴屏**
3. 短边 > 1800mm（可双侧布置）：
   - 面积 > 6㎡ / 主卫宽裕 → **矩形淋浴房**（面积 ≥5㎡ 可加浴缸）
   - 面积 ≤ 6㎡、通道紧 → **钻石淋浴房**（斜角省通道）
   - 中等、想半开放 → **L型淋浴屏**（与矩形二择）

大公卫 / 主卫多人同时使用 → 在上述形态上叠加**分离式**：用预留隔墙 / 凸凹（支点 ③）把洗漱、如厕、淋浴分隔成可独立使用的隔间，台盆可外置。

## 各模式：墙面分配 + 选型

**一字淋浴屏**：洁具全沿同一侧长墙排列（**开阔侧**：门偏哪端，洁具放另一端，进门直达不折返），一字屏横跨短边占尽端、临窗，对侧留连续通道。台盆靠入口端、马桶居中、淋浴最深。花洒装在**一字屏所连两实墙之一**（垂直于屏的侧墙、非窗墙）、相对整个淋浴区**居中**（哪面侧墙不限）。`【自查·坐标】花洒在屏所连侧墙实墙上，其中心对齐淋浴区在该侧墙方向上的中点。`
> 两面长墙等长时，台盆墙长优先无从区分，由动线（开阔侧）破平。

**矩形淋浴房**：以门为界，**马桶 + 矩形淋浴房共占门侧**（上下叠放），**台盆独占对侧整墙**。浴缸变体占第三面墙、长边靠墙、优先靠窗。

**钻石淋浴房**：钻石房占**深处角落、斜面朝室内**（便于进出 + 斜角省通道）；台盆占剩余墙里较长一面；马桶占短段。

**L型淋浴屏**：L 屏占远离入口角落、两边贴两面实墙、开放面朝内；台盆占长墙；马桶占短段。与矩形 / 钻石互斥。

**半卫**：台盆 + 马桶。台盆门侧墙贴角，马桶可用如厕段居中。

模块速查（按形态与适配选；精确 id / 尺寸以 `projectMount/modules/module_library.json` 为准，库有变动以库为准）：

| 洁具 | 形态 | 适配 / 尺寸（指示值） |
|------|------|------------|
| 台盆 | 标准 / 定制 | 标准定尺；可用墙 >850 换定制（水平填充，越长台面越大） |
| 马桶 | 定尺 | 约 400×650，不随墙变 |
| 一字屏 | 水平填充 | 宽度填满短边、连两实墙 |
| 矩形 / 钻石 / L型淋浴房 | 参数化 | 角落布置，约 800–1200 见方（钻石斜面切角省通道） |
| 花洒 | 定尺小件 | 湿区内实墙、非窗墙 |
| 浴缸 | 参数化 | 长边靠墙，仅面积 ≥5㎡ |

## 一个落地示例（照此推你自己的空间）

空间：X[9500,11100] = 1600 宽、Y[7100,9700] = 2600 深；西北角管井 X[9500,9800]×Y[8800,9700] = 300×900；门在南墙偏东，窗在北墙偏右。

短边 1600 ≤ 1800 → **一字淋浴屏**。单一最优，不造第二方案。

- **一字屏**：落在 **Y=8800**（管井下沿）—— 把管井吞进湿区（支点 ③）。屏从**管井东面 X=9800 横跨到东墙 X=11100，长 1300mm**，两端各落一面实墙。
  关键：Y=8800 以北净宽只有 **1300**（管井吃掉西侧 300），**不是 1600**。
- **台盆 + 马桶**：门偏东 → 开阔侧在西 → 沿**西墙下段**（X=9500，Y[7100,8800]）。因管井被屏吞进湿区，这面干区墙平直连续 1700mm。台盆贴南墙角靠入口，马桶在台盆北沿 ↔ 屏南沿的如厕段居中。
- **花洒**：湿区内**东墙北段**实墙（facing 西），不靠窗墙、不悬空。
- 对侧（东侧）留连续通道，进门左转直达台盆。

**反面（一次真实失败，引以为戒）**：

- 屏只做 600mm、停在半空没够到东墙 → 湿区不封闭，花洒随之读作悬空；且 600 < 模块最小 800。
- 又硬造了一个"东墙布置"的第二方案，靠违反开阔侧来凑差异 —— 卫生间不需要。
- 这两处 **validate 都报 0 错误也照样错**：validate 只兜底碰撞 / 边界 / 禁区，"屏是否连两墙""花洒是否贴墙"它不查 —— **你必须自己算坐标（屏长 == 两墙净距）+ 识图确认**。

## 硬约束（底线，必须满足）

- 一字屏 / 淋浴**必须连两实墙**，整个 bounds 落在两墙之间。`【自查·坐标】一字屏沿墙跨度 == 两端实墙净距（按 boundarySegments 实算，不取模块默认/最小值充数；不短于模块 min）。`
- 窄卫（短边 ≤1800）洁具同侧，**对侧通道 ≥700mm** `【自查·坐标】短边≤1800 时所有洁具同侧、对侧通道≥700。`
- 洁具**避门洞**：不占门洞段、不被开门扫掠区压住。
- 浴缸仅面积 ≥5㎡ 用；与淋浴面积足则分区并存、不足则二择。

## 你做主（自由区）

洁具间精确间距、花洒确切高度、配件（毛巾架 / 镜柜 / 壁龛）位置 —— 按现场判断，不设规则。
