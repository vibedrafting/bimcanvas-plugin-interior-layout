# 空间设计（怎么读空间 · 怎么组织空间）

## 0 · 宪章

- **定位**：本文件是「**空间认知 + 空间组织**」叙事的唯一归宿——回答"这个空间怎么读、怎么分"。
- **只答**：动线/纵深/采光/安静度（怎么读）+ 分区/功能带/留白/隐私梯度（怎么组织）。
- **不答**（→ 别处）：家具怎么放（墙面归属/朝向/通道数值/顶角 → `furniture_placement.md`）；做得好不好（品质维度 → `design_evaluation.md`）；某房型特异解法（床头墙筛选/卫生间模式 → `bedroom/bathroom/livingroom.md`）。
- **谁消费**：感知阶段读第一幕，规划阶段读第二幕。
- **约束力 = 自查仪器（P6）**：质量规则带 `【自查·坐标/validate】` 为硬、`【自查·视觉】` 为软、无锚为留白。本文件多为"读 / 组织"判断（动线 / 节奏 / 隐私梯度好不好属留白、交用户终选），少数可坐标核验者带自查锚。

## 1 · 锚定速览

**空间阅读三要素**（读）：动线方向 · 纵深层次 · 采光轴。
**安静度**（读）：标"安静"前必先核查墙背靠什么——背靠公共空间/卫浴排水/电梯井 = 噪音源。
**分区分界线**（组织）：

| | 分界线落在哪 | 判定 |
|---|---|---|
| ✓ | 内凹角 / 建筑转折 / 门洞 / 主家具占用与通道的自然边界 | 有意义的分区 |
| ✗ | 两侧均为完整实墙的墙面中部凭空横切（如把一面完整北墙拦腰切给两个区） | 无意义的分区 |
| ✓ | 单功能、无真建筑边界 → **不物理分区**（leafCount=0，用语义功能带） | 优于强切 |

## 2 · 第一幕：空间怎么读

### 空间阅读三要素

1. **动线方向**：入口到各功能区的行走路线。主通道连贯无阻断。
   - **【必须·R1.8】** 主通道不得被家具阻断/折返——动线断裂导致日常走动反复绕行 = 设计失败。
2. **纵深层次**：入口侧 = "前场"（过渡/储物），远端 = "深处"（私密/休息），密度前高后低——渐进节奏创造空间体验。
3. **采光轴**：窗户是"呼吸面"。
   - **【必须·R1.9】** 不得用高大家具切断窗→深处的光线通路——遮挡让空间变暗变压抑。

### 安静度判据（标"安静"前置核查）

**【必须】** 给任一墙面下"安静"结论**之前**，先核查它背靠的相邻 zone / 房间类型：

- 背靠 **LivingRoom / 公共空间 / 卫浴排水墙 / 电梯井 / 公共走道** → **噪音源**，不得直接标"安静"，记"背靠 {邻接房型}，安静度需降级评估"。
- 邻接关系无法判定 → 记"邻接未明、安静度待核"，**不得默认安静**。

> WHY：背靠公共空间的墙若被骨架标"安静实墙"，后续选床头墙会把噪音墙当优选。陈述邻接房型是几何事实。
> **【提示·粒度局限】** "背靠卫生间"不等于"一定吵"——实际取决于卫内上下水墙贴在哪一侧；单设计区拿不到卫内布局时，**只作"待核"的排序参考，不据此对床头墙下淘汰结论**（房型对安静度的应用见 `bedroom.md`）。
> **【提示·门位反推排水墙】** 卫内布局未知时，可由**卫生间门的位置**反推上下水墙：台盆 / 排水常布在进门一侧或其正对墙；若据此估出的排水墙**不在**卧室与该卫共享的隔墙这一侧，则该隔墙背靠的是卫生间干区、**不降级**。例：主卫门偏西 → 台盆多布在进门侧（东墙）→ 主卧与主卫的共享西隔墙背靠干区、不吵。门位是设计区可见信息（通邻区的门已知），优先用它把"一律待核"细化为启发式推断；仍属软判据（含不确定），只升降排序、不淘汰。

### 房型保真护栏（读空间时）

- **只描述客观空间属性**：动线/纵深/采光/安静度/墙面长短与完整性（有无窗、有无门段）。
- **【禁止】** 写房型专属功能命名（电视墙/床头墙/沙发区）——那是规划期依房间策略才能下的功能定性；"最长完整实墙"只陈述为**墙面资源**，不预判功能。

## 3 · 第二幕：空间怎么组织

### 功能分区与意图

- 封闭空间通常 2-3 个功能区，各区有"锚定墙面"，家具群组围绕此墙面组织。**用动线自然分隔，而非家具硬隔断。**
- **分区赋予空间以意图**——有意图的空间才产出有设计感的布置；家具属于各自区域的功能叙事，区域间留白是有意识的空间节奏。
- 分区线**不是先把房间切成矩形再填家具**，它从主家具粗占位、通行路径、有意留白中**浮现**。

### 【必须】分区分界线判据（缺口a 核心）

- **分界线必须锚定建筑特征**：内凹角 / 墙体转折 / 门洞 / 主家具占用与通道形成的自然边界。
- **【禁止】** 在**两侧均为完整实墙**的位置凭空横切（把一面完整长墙拦腰切给两个区——分界两侧都是中段墙面、无任何建筑依据）。
- **【禁止·无效判据】以「面积小 / 区域不够大」论证分或不分**——面积不是分区判据（小面积照样能独立成区：壁龛书房、玄关入户柜区）。分 / 不分只看两条：① 分界线有无建筑锚点；② 物理分割是否切断有价值的连续资源（如长墙储纳）。
- **无真建筑边界且功能单一 → 不物理分区**（leafCount=0，输出语义功能带即可）**优先于强行切分**。

> WHY：分区是为了让空间有意图；横切完整墙的"分区"不对应任何空间体验，纯属为显得专业而分——它还会把一面本可连续利用的长墙人为切断（如把完整北墙切两段，衣柜就摆不满）。"不分区"是合法且常常更优的结论。

### 留白与隐私梯度

- **有意留白**（入口缓冲/主通道/采光留白/操作净空）不强制生成功能子区，但须说明位置与目的。
- **无意残留**（既非通道也非收纳的 <600mm 窄缝、大块说不出功能的空区）是问题，不是设计。
- **隐私梯度**：入口（过渡/公共）→ 深处（私密/静态）逐级递进。
- **【视线遮挡机制】** 要遮挡某区域不被入口直视，遮挡元素须**垂直于视线、投射入空间**（隔断 / 屏风 / 垂直于墙伸入房间的柜段）——**顺墙贴布的家具（沿墙长边贴墙的柜）不构成遮挡**，它与被遮挡区在同一视线侧、挡不住。例：想从入口遮挡床区，须用垂直入房的隔断段；衣柜顺西墙贴一长条遮不住床（Test#5 l-shape-wrap 真因）。
  `【自查·坐标】若变体目的含遮挡：须存在垂直于视线、投入房间的遮挡段（bounds 长边离墙）；全是顺墙贴布段 = 遮挡未兑现。`

> 通道的**数值标准**（主≥900/次≥600/床侧等）属放置法则，见 `furniture_placement.md`；本文件只讲"哪里该留通道/缓冲"的组织意图。

## 4 · 精选示例（分区 ✓ / ✗）

**L 形空间（主体矩形 + 一个延伸翼）**：
- ✓ **沿内凹角切分**：以"主体↔延伸翼"的内凹转折为界——延伸翼做更衣/储物前场，主体做睡眠区。分界线对应真实建筑转折，两区各有完整墙面资源。
- ✓ **或不物理分区**：若主体本身单功能、延伸翼小，直接用语义功能带（leafCount=0），不切叶子。
- ✗ **横切主体矩形**：在主体中部画一条 Y 线把"完整北墙 + 完整南区"拦腰分成两个 dz——分界两侧都是完整墙面、无建筑依据，还把本可连续做衣柜的北墙切断。（Test#3 dressing-corner/east-bed 即此）
