# 设计品质维度

> 好的设计不是先随便做、再检查有没有碰巧做对——好的设计从第一步就知道自己要往哪走。
> 这五个维度既是**策略阶段的设计目标**，也是**审查阶段的验证标准**。
> 有了"进门直达台盆"的目标，选墙时不需要公式；审查时只需验证"进门后首个使用点是台盆吗？"——目标驱动让每个决策都有判据。

---

## 两层评价

```
Layer 1  工程合规    "有没有错？"    几何合法 + 通行可达 + 功能完整
Layer 2  设计品质    "好不好？"      下文五个维度
```

每层是上一层的前提——有错误的布局谈不上品质。Layer 1 不通过时不进入 Layer 2。

**区分**：900mm 通道宽度是 Layer 1 底线（"能走过去"）；但一条 900mm 的通道如果需要折返再前进，Layer 2 的动线设计仍不合格（"走得不自然"）。

**截图复核**：`validate_layout` 通过只代表几何合法，不代表设计自然。截图审查时必须看当前视觉证据，尤其检查：
- 窗帘是否按合同完整到达两端墙面，是否因验证碰撞被截断。
- 衣柜是否无故偏小，门侧留白是否有明确用途。
- 卧室床体是否过度占压空间，导致收纳、窗帘或通道被动让步。
- 留白是否是入口缓冲/通道/操作净墙，而不是家具放完后的残留。

## Layer 1.5 通用品质（`通用品质` 维用）

> 本节供评审的 `通用品质` 维使用，回答"放得**规不规整 + 有没有浪费**"——介于 Layer1"能不能放"与 Layer2"好不好"之间。**判四项**，与 Layer1 / Layer2 不重叠。

| 子项 | ✓ | ✗ | 视觉检查问法 |
|------|----|----|------------|
| **靠墙完整性** | 大型家具贴靠实墙 / 墙角，连续家具面无无故断口 | 家具悬空离墙、连续柜面被无故插断留缝 | "哪些大件家具的背面与墙之间有可见空隙？" |
| **相邻空隙** | 同组相邻家具间隙=使用间隙（贴合或刻意操作净空） | 相邻家具间 <600mm 的无意窄缝（既非通道也非收纳） | "同组相邻家具之间有无既非通道也非操作区的窄缝？" |
| **对齐 / 转角闭合** | 同墙家具前缘 / 端线对齐、朝向一致；L 形相邻两段在转角**闭合**（端部互贴或贴到垂直墙） | 同墙家具参差 / 朝向杂乱；**L 转角未闭合——端部没贴到垂直墙、留下够不到的角部封闭空袋（贴墙卫生死角，如东墙衣柜短 50mm 没顶到北墙）**；**柜列自由端悬在墙段半中腰**——既未贴垂直墙也无家具续接、剩余墙段无登记理由（如 1550mm 墙只用 800mm 柜、750mm 空段悬空） | "同墙柜面前缘是否齐平？L 转角处有无可见缝隙？**每条柜列的两端分别贴着什么**？" |
| **空间利用** | 墙段 / 区域被家具占用，或空置且豁免成立（见下） | **大块墙段或区域既无家具、又无成立的留白理由**——空置即浪费（如最长实墙整段裸露、延伸翼整片空置；主卧北墙 + NE 延伸区双空置即此） | "哪些墙面大段裸露？哪些区域既无家具又不像通道？" |

**【判定手段·坐标台账为基底 + 逐维定点识图】**先从 `modules.json` + 边界数据建逐墙坐标台账（每面墙：有效长度、被哪些家具占用、剩余空段与柜列端部归宿），再**按子项逐个定点识图**取视觉证据（问法见上表）。几何 / 数值可判项以坐标为准；识图负责交叉佐证与"坐标看不见"的问题（渲染异常、整体观感）。

**【必须·空置豁免口径】**空置豁免须同时满足：①理由**几何成立**——属通道 / 操作净空 / 门弧 / 入口缓冲等**可坐标验证的类型**，叙事性留白（"开阔感""视觉呼吸""释放墙面"）不构成本维豁免（其合理性归 Layer2 `空间意图` 维评判）；②理由**出自施工简报已声明的「保留空段」条目**——简报没登记的空置不豁免，**评审不得替方案补写豁免理由**（反例：北墙 4070mm 空置、简报未登记，评审自行脑补"多向环流缓冲"放行）。

**【必须·空间利用边界】**本项只判**客观有没有大块空置**（坐标事实、任意房型通用、**不设长度阈值，定性判断**）；留白是否有节奏 / 意图属 Layer2 `空间意图` 维，两者不重复。

**【必须·边界声明】通道宽度 / 通行可达属 Layer1，不在本维复述。** `通用品质` 维**不复核**"床前 950mm 通道""≥900mm 主通道"这类通行宽度——那是 `validate_layout`（Layer1）的职责。本维只判上表四项，发现通道问题应交回 Layer1，不在本维记 finding。

## 设计品质维度

### 动线设计

> 来自空间阅读·动线方向——人每天走进房间的路线决定了使用体验。
> **核心问题**：从入口到每个功能点的路径直觉吗？功能沿动线递进吗？

**声明时**：描述入门路径意图，用 `(动线)` 标签
- `进门右转直达台盆(动线)`
- `餐桌靠近入口缩短上菜动线(动线)`

**判断时**：
- ✓ 卫生间门偏西，洁具放东墙——进门自然右转直达台盆
- ✗ 卫生间门偏西，洁具放西墙——进门后要折返
- ✓ 卧室：更衣区在入口侧，床在深处——进入即到达使用点
- ✗ 卧室：床紧挨门口，入门即见床——无过渡，路径无逻辑

**视觉检查**："从入口到床 / 衣柜 / 各使用点的路径上，有无家具阻断或被迫绕行？"

---

### 空间意图

> 来自 generate-zoning「分区赋予空间以意图」——没有意图的空间只是家具放完后的剩余。
> **核心问题**：每个区域有可命名的功能身份吗？有无意识的剩余空间吗？

**声明时**：命名区域的功能角色，用 `(空间意图)` 标签
- `L形延伸作为独立换衣区(空间意图)`
- `凹角赋予书桌工作区身份(空间意图)`

**判断时**：
- ✓ L形延伸做更衣区——异形空间被赋予明确功能
- ✗ L形延伸空置——"家具放完剩下的"
- ✓ 有意识的留白：入口缓冲区（过渡需要）、主通道（动线需要）
- ✗ 无意识的残留：<600mm 窄缝，既不是通道也不是收纳

**视觉检查**："有没有说不出功能的剩余区域？每块空区像通道、缓冲，还是像'家具放完剩下的'？"

---

### 功能叙事

> 来自 generate-zoning「家具属于各自区域的功能叙事」——连贯的故事胜过碎片堆砌。
> **核心问题**：同一区域的家具讲述连贯的功能故事吗？

**声明时**：描述家具群组形成的功能主题，用 `(功能叙事)` 标签
- `东墙统一洗漱+如厕功能(功能叙事)`
- `北墙L形衣柜构成连续存储叙事墙(功能叙事)`
- `电视柜+沙发+茶几形成完整休闲叙事组(功能叙事)`

**判断时**：
- ✓ 台盆+镜柜+毛巾架组成洗漱区——功能群组连贯
- ✗ 衣柜-空隙-床头柜-书桌混杂同一面墙——碎片化堆砌
- ✓ 连续衣柜墙——换衣视线所及全是收纳，存储叙事无断点
- ✗ 衣柜被梳妆台插断——存储叙事断裂，功能混杂

**视觉检查**："同一面墙 / 同一区域的家具是否构成连贯的功能组？有无被无关家具插断？"

---

### 空间节奏

> 来自 generate-zoning「区域间的留白是有意识的空间节奏」——有意识的递进而非均匀填充。
> **核心问题**：入口到深处有隐私/密度的递进吗？留白是有意识的吗？

**声明时**：描述从入口到深处的功能序列，用 `(空间节奏)` 标签
- `洗手→如厕→淋浴由浅入深(空间节奏)`
- `入口→换衣区→床的隐私递进(空间节奏)`
- `餐厅(过渡)→客厅(核心)→窗景(深处)的渐进体验(空间节奏)`

**判断时**：
- ✓ 卫生间：台盆(公开)→马桶(半私密)→淋浴(最私密)——隐私梯度清晰
- ✗ 马桶紧挨门口——进门一览无余，隐私梯度倒置
- ✓ 卧室：更衣区在入口侧（过渡），床在深处（私密）
- ✓ 客餐厅：餐厅靠入口（过渡/半公共），客厅朝窗（休闲/深处）

**视觉检查**："从门口望进去，功能密度是否由疏到密、隐私由浅到深递进？有无私密功能暴露在入口？"

---

### 采光通风

> 来自空间阅读·采光轴——窗户是室内最珍贵的资源，不应被浪费。
> **核心问题**：窗户资源被合理利用了吗？光路通畅吗？

**声明时**：描述功能与光线的匹配关系，用 `(采光通风)` 标签
- `梳妆台靠南窗采光(采光通风)`
- `南窗最优采光给主活动区(采光通风)`

**判断时**：
- ✓ 梳妆台/书桌靠窗——需要自然光的功能获得了采光
- ✗ 高衣柜正对窗——切断光线，深处空间变暗
- ✓ 客厅主活动区朝南窗——使用频率最高的区域得到最优采光
- ✓ 卫生间淋浴区临窗——通风排湿（此处临窗是正面示例，非违规）

**视觉检查**："窗前 / 采光路径上有无高家具遮挡？需要自然光的功能（梳妆 / 书桌）离窗多远？"

---

### 家具最优布局

> 来自房间策略·家具优先级——稀缺的优质墙面应优先满足最重要的家具，长直实墙不应无功能闲置。
> **核心问题**：每件主家具是否落在其**最优墙面**并充分利用？
> **【注意】最优墙 ≠ 一律最长墙**（软指导）：最长连续实墙常是好候选，但若它是**床对面的窄维度墙**、放衣柜会把睡眠区/床尾通道压到下限（见 bedroom.md 床前通道检查），则它对衣柜**不是**最优墙——此时垂直的次长墙（如北墙）才是。最优 = 兼顾家具功能、又不挤占他者（睡眠/通道）的墙。

**边界声明**：本维只判"优质墙面是否优先给了最重要家具"的**资源分配最优性**；不复述空间意图的"残余空间"、功能叙事的"连续性"——那是另两维的事。本维**不设墙段长度阈值**，定性判断"是否偏离最优"。

**声明时**：描述主家具的墙面归属理由，用 `(家具最优)` 标签
- `衣柜占能兼顾收纳又不挤占睡眠/通道的最优墙并填满有效段(家具最优)`
- `床占侧对窗、远离门的连续实墙(家具最优)`

**判断时**（按家具重要度排序核验，重者优先）：
- ✓ 主收纳（衣柜）占用其最优墙（够长、且非挤占睡眠/通道的床对面窄墙）、填满有效段
- ✗ 衣柜挤在短墙/角落，而**更优的长墙**（够长且不压睡眠/通道）空置或让给低优先功能——主家具未得最优墙
- ✗ 衣柜占了最长墙，但那是**床对面窄维度墙、把床尾通道压到下限**——唯长墙、未顾及通道，不算最优（本户型西墙即此）
- ✓ 连续实墙跨主体区+延伸区时整段用于同一主家具（如衣柜连续展开），不被分区人为切断
- ✗ 连续实墙被分区人为切断，主家具只用其中一小段，同段其余连续墙闲置
- ✗ 长直无窗实墙既无家具又无明确留白理由——按家具重要度本应承载主家具
- ✗ **主家具只用了所在墙段的一部分**——同墙剩余可用段无登记理由（段内浪费与整墙空置同罪，如 1550mm 墙只放 800mm 柜）

**视觉检查**："最长的几面实墙分别被什么占用？有无明显空置的长墙或半截空置的墙段？"

### 储物充分性与设计合格底线

> 来自 Test#3 教训——差异化曾靠欠设计凑多样（北墙留空冒充"步入式"、西墙全空冒充"留白"）。本节是**合格门槛**，不是又一个打分维度。

**【必须·反伪开放】** 开放式衣帽间 / 步入式 / 留白美学等概念词**不豁免储物充分性**——
- 主收纳（衣柜等）必须落在其最适长墙并填满有效段；把黄金收纳墙留空、收纳挤进小角致储物明显不足，**就是欠设计**，不因冠以"开放/步入式"而合格。
- 最长实墙整面空置 + 本可放的家具被省略，**就是浪费**，不因冠以"留白增加空间感"而合格。
- 概念词只描述取向，**不构成欠设计的合理化理由**；留白是否有意识属 `空间意图` 维，储物够不够属本节，两者都要过。

❌ 反例（Test#3）：`dressing-corner` 北墙东段（黄金收纳墙）留空、衣柜挤 NE 角（延米 2600 vs 满墙 4500），以"步入式"包装；`east-bed` 西墙 4850mm 整面空置且省略本可放的梳妆台，以"留白"包装。两者储物充分性不合格。

**【必须·合格底线前置闸】** 一个方案/变体在进入「多方案差异化对比」之前，**必须先各自独立过合格底线**：
- 主家具落在最优墙（`家具最优布局` 维成立）；
- 各类储物达到房型合同标准（衣柜/收纳延米不低于底线）；
- 空间充裕时本可放的可选家具不无故省略（**可选家具候选须先扫描所有墙段发现、再决定放/省略——不得跳过发现直接省略，也不得在候选未发现前就问用户**）。

未过合格底线的方案**标"不合格"、不参与差异化对比**。**差异化只在合格集合内取**——宁可方案数少而精，不靠降级凑多样（对接 `multi-variant-diversity` skill 的同名前置闸）。

> WHY：用户买的是"几个都合格、但各有取向"，不是"一个好 + 两个凑数"。合格是门槛、差异化是门槛之上的选择。

## 维度选取参照

### 空间特征 → 优先维度

| 空间特征 | 优先选取 |
|---------|---------|
| 入口位置偏向一端（非居中） | 动线设计 |
| 明显的入口→深处轴向 | 空间节奏 |
| 异形区/L形延伸（≥3m²） | 空间意图 |
| 多件家具集中同一墙面 | 功能叙事 |
| 自然采光明显（大窗/朝南） | 采光通风 |
| 多件主家具竞争优质墙面 / 存在长直无窗实墙 | 家具最优布局 |

无显著特征时的默认组合：

| 房间类型 | 默认维度 |
|---------|---------|
| 卫生间 | 动线设计 + 空间节奏 |
| 卧室 | 空间节奏 + 功能叙事 + 家具最优布局 |
| 客餐厅 | 功能叙事 + 空间节奏 + 采光通风 |

### 声明格式

```
**设计目标**：[目标描述(维度名)] / [目标描述(维度名)] / [目标描述(维度名，如有)]
```

示例（卫生间）：
`**设计目标**：进门右转直达台盆(动线) / 东墙统一洗漱+如厕功能(功能叙事) / 洗手→如厕→淋浴由浅入深(空间节奏)`

示例（主卧）：
`**设计目标**：L形衣柜构成连续存储叙事墙(功能叙事) / 入口→换衣区→床的隐私递进(空间节奏) / 梳妆台靠南窗采光(采光通风)`

示例（客厅）：
`**设计目标**：电视柜+沙发+茶几形成完整休闲叙事(功能叙事) / 餐厅→客厅→窗景的渐进体验(空间节奏) / 南窗采光最大化给主活动区(采光通风)`
