# 家具放置法则（通用）

## 0 · 宪章

- **定位**：本文件是「**家具怎么放·通用法则**」叙事的唯一归宿——跨房型通用的墙面归属/朝向/贴墙/通道/门段/顶角/填满/依赖法则。
- **只答**：与房型无关的放置规定。**module_library 各家具条目的通用法则只一行点睛 + 指向本文，全文权威在此。**
- **不答**（→ 别处）：空间怎么读/怎么分（→ `spatial_design.md`）；做得好不好（→ `design_evaluation.md`）；房型特异选墙/范式（床头墙筛选/衣柜L决策/卫生间模式 → 房型文件）；落坐标的施工程序（闭合预检/修正阶梯 → `placement-procedure` skill）。
- **谁消费**：规划与落地阶段。

## 1 · 锚定速览（9 条放置法则）

| 规则 | 级别 | WHY |
|------|------|-----|
| 靠墙 | 【建议】 | 释放中央活动区域，减少碎片化 |
| 居中 | 【建议】 | 视觉均衡（电视柜居中电视墙、床居中床头墙） |
| 顶角 | 【建议】 | 大家具贴靠实墙角，窄缝(<600mm)积灰成卫生死角 |
| 朝向 | 【建议】 | 背面靠墙=心理安全感，正面朝空间=便于使用 |
| 对位 | 【建议】 | 相关家具功能对应（沙发对电视、餐椅围餐桌） |
| 避窗 | 【建议】 | 窗前大家具遮光且压缩空间感（卫生间淋浴区例外） |
| **避门** | **【必须】** | 不阻挡门开启范围——门扇受阻导致功能丧失 |
| 前瞻协调 | 【建议】 | 放主家具时预判可选家具的策略位置，避免阻断其空间需求 |
| **优先级省略** | **【必须】** | 空间冲突迫使省略组内元素时，按优先级**从低到高**省略——不按物理位置截断末端（截断末端=让组装方向决定取舍，而非设计意图决定） |

## 2 · 分级规则体

### 【必须】硬约束（违反即 validate_layout 报错 / 功能丧失）

1. bounds 完全在 zone.innerBoundary 内——超出=穿墙。
2. bounds 不与 zone.exclusionAreas 重叠——禁区是柱子/管道等不可占用区。
3. bounds 不与其他已放模块重叠——两物体不能占同一位置。
4. 不阻挡门的正常开启（R1.1 避门）。
5. **不二次扣减完成面（R1.2）**：innerBoundary 已扣除墙面完成面厚度，**直接以它为可用范围，不要再额外预留**——二次扣减导致可用空间白白缩小。

### 【建议】软指导（默认遵守，可说明理由后偏离）

**布置优先级（锚点 → 主要 → 可选）**：锚点=功能核心（由空间决定）；主要=由锚点+空间共同决定；可选=功能补充。**WHY+【必须】**：优先级决定执行顺序，但所有家具在策略阶段**同步探索**——可选家具位置可能影响主家具最优布局（房型的锚点/主要/可选清单在房型文件）。

**通道与间距**：

| 通道类型 | 最小宽度 | 场景 |
|----------|---------|------|
| 主通道 | ≥ 900mm | 入口→核心区主动线 |
| 次通道 | ≥ 600mm | 家具间穿行、床脚到墙 |
| 床侧·使用侧 | ≥ 500mm | 日常上下床 |
| 床侧·窗侧 | ≥ 200mm | 仅预留窗帘空间 |

- **通行间隙 vs 使用间隙（R1.3·关键）**：通道标准只适用于**人需从此处走过到达别处**的间隙；人在旁边伸手操作即可的间隙（床头柜与相邻衣柜之间）**无最低通道要求**。**通道扣减只扣家具实体深度，使用区与通行通道分时复用、不重复扣减。** WHY：区分通行与使用，避免所有间隙都按最大标准留而浪费空间（梳妆台被"实体400+使用区600"双重扣减误判不可行即此）。
- **门侧净空**：门所在墙布置柜体时，门洞旁至少保留一侧可操作净墙。次卧默认 ≥300mm，主卧 ≥450mm；紧凑可压一档（次卧≥200/主卧≥300）。仅用于开关操作，**不等同于**床头墙筛选的"门段缓冲"（后者见 bedroom.md）。
- 通用使用距离：餐椅后退 600-800mm，书桌椅后退 800-1000mm。

**门扇类型选择**：柜门前方净空 ≥600mm 用平开门；<600mm 用移门。

**填满有效段**：柜列应填满其墙面有效段全长（标准柜阵列 + 定制柜补足），剩余墙段需有登记的留白理由。WHY：连续柜面视觉整洁且最大化收纳；半截空置墙段=段内浪费（同墙剩余可用段无理由空置，与整墙空置同罪）。

**顶角闭合处置**：贴墙柜列两端须顶死垂直墙或与相邻家具互贴；转角处两段在角部闭合。残量（<600mm）**挪向门口/通道侧**，不留在墙段半中腰成封闭卫生死角。

**家具依赖（成套同阶段·R1.5）**：睡眠组(床+床头柜)/客厅组(沙发+茶几)/餐厅组(餐桌+餐椅)/工作组(书桌+椅)——同组**同阶段放置**，床头柜紧贴床头两侧。**功能互斥**：同区不重复放同功能家具（儿童房双床除外）。

**常见错误速查**：

| 错误 | 正确做法 | WHY |
|------|---------|-----|
| 家具挡门 | 检查门扇弧线区域 | 门无法打开=功能丧失 |
| 通道过窄 | 主≥900/次≥600 | 人体通行最低需求 |
| 沿墙留卫生死角 | 贴靠实墙角，空隙留通道侧 | <600mm 窄缝积灰无法利用 |
| 重复扣减完成面 | innerBoundary 已扣，直接用 | 二次扣减白缩空间 |
| 成套坐标逐件估算 | **组装锚 + 顺序累加**：锚坐标→依次加各件尺寸，每件 gap=0 | 逐件估算在紧贴处引入安全缓冲、积累成可见缝隙；顺序累加是闭合系统、结构性消缝 |

## 3 · 精选示例（成套坐标）

**睡眠组沿西墙（床头靠墙、双床头柜）**：
- ✓ 顺序累加：窗侧锚 Y=1100 → 窗侧床头柜(+450) → 床(+1800) → 使用侧床头柜(+450)，每件 gap=0，闭合无缝。
- ✗ 逐件估算："床大概在中间，两边各放个床头柜"——紧贴处各留 100-200mm 直觉缓冲，积累成肉眼可见空缝。

## 4 · 模块间冲突仲裁（多个模块争同一墙段时的权威裁决）

| 冲突 | 裁决 |
|------|------|
| **凹位/异形区残余墙段** 归谁 | 梳妆台 > 通用定制柜（梳妆是单一采光/组合偏好，通用柜多场景可退） |
| **L 形转角权** | 主衣柜（床头周边主收纳） > 延伸区通用柜 |
| **顶角残量处置** | 统一标准：转角**必闭合**（优先级1）> 残量挪通道侧（优先级2）——多模块不得各自判断 |
| **梳妆台扩宽消缝 vs 柜体连续面** | 不得插断连续衣柜面（柜体优先）；必须组合时梳妆台扩宽作次序 |

> module_library 各模块的 topology/relation 只一行点睛 + 指向本节，冲突以本表为准。

## 5 · 速查 + 边界回指

- **硬红线**：innerBoundary 内 / 不重叠 / 不阻门 / 不二次扣墙厚 / 避门 / 优先级从低到高省略。
- **边界回指**：哪里留通道/缓冲的组织意图 → `spatial_design.md`；布局好不好 → `design_evaluation.md`；房型特异选墙/门段缓冲/范式 → 房型文件；落坐标的闭合预检/修正阶梯/自改图边界 → `placement-procedure` skill。
