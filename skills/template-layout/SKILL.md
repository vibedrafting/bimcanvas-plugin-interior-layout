# 收敛型布局规划（套模板）

收敛型空间的最优布局由**房型模板确定性推出**，不需要探索式双思维（探索只会造"方式A / 方式B"伪候选、给自由发挥留口子）。本方法只做一件事：**按房型模板把布局算出来**。

## 怎么做

1. **读房型布局模板**：本次 `load-design-knowledge` 已按房型注入对应设计文档（如 `bathroom.md`），其中写有该房型的**决策树 / 布局模式 / 排布支点**——这就是模板。
2. **套模板算布局**：按模板决策树定模式 → 按模板支点确定性推出**每件家具的墙面归属 + 入口→深处的排布顺序**。墙面归属是**按模板算出来的，不是比选 / 自由发挥**。
3. **产出「方案草稿」**：写 `### 方案草稿 · 分区思维`（功能带 / 干湿带归属）+ `### 方案草稿 · 顺序思维`（锁墙顺序）两子节（只记墙面归属 / 相邻，不写坐标），交调用方按 `design-doc-upsert` 写父 DESIGN.md。

## 纪律

- **确定性、不自选墙**：墙面归属严格按模板的选墙规则推出（如卫生间「开阔侧定墙」）；**禁**"某墙最优质 / 最长 → 选它"这类绕过模板的自由选墙。
- **不列候选**：收敛型只有一个最优解，不产"方式A / 方式B"伪差异。
- **模板未覆盖才自主**：模板定的照落；模板留白处（配件位置等）才自主判断。
